# 놀러가자 분류·이용 조건

- 전국 17개 시·도, 7개 활동 대분류·34개 세부 종류, 동행 구분. 상시 방문·축제·참여 이벤트·할인·쿠폰 성격을 활동 종류와 별도 저장.
- 전체 이용 무료 / 입장 무료(부대비용 별도) / 유료 / 혼합 / 확인 필요를 분리. 자유 방문·예약 권장·예약 필수·입장권 확인과 1인 참여 여부를 독립적으로 표시.
- 최소·최대 인원, 요금 범위, 준비물, 참여 대상, 특이사항, 혜택 대상·참여 방법·제외 조건 입력 지원.
- 회원 글은 기존 posts.extra JSON의 play에 저장. DB 스키마 변경 불필요. 작성·수정 모두 서버에서 enum, 분류 조합, 인원 범위, 필수 조건 설명, 유해어를 검증. 이전 글은 optional 필드로 호환.
- 일반 수정 폼에서도 입력·수정·초안 보존. 나들이 글의 활동 태그와 혜택 배지는 새 조건에 맞춰 서버에서 정규화.
- 조건 미등록은 무료·자유 방문·무제한을 뜻하지 않음. 카드와 본문 상단은 미확인을 명시. 기존 편집 콘텐츠는 출처에 있는 범위만 분류하고 인원·제한은 추정하지 않음.
- 회원 목록의 조건 필터는 Supabase JSON containment 또는 로컬 저장소 predicate로 페이지네이션 전에 적용. 총 개수·페이지 링크에 필터 유지.
- 회원 글의 행사 날짜 자동 분류는 기존 범위를 유지하며 이번 변경에 포함하지 않음.

검증: 조건 서버 검증, 무료 범위 분리, 저장·수정·페이지네이션(격리 로컬 DB), 실제 등록폼 입력과 제출 payload(서버 액션 mock, 공개 글 생성 없음), 기존 축제·SEO 회귀, 타입·빌드·브라우저·운영 확인.
