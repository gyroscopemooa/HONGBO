# 국내 여행지와 검색 정보 보완

2026-11-11: 대한민국 구석구석의 태화강 국가정원, 대왕암공원, 경주 동궁과 월지, 환호공원 스페이스워크 안내를 확인하고 독자적인 짧은 소개와 방문 계획 팁으로 추가했다. 원문과 확인일은 각 상세 페이지에 표시한다. 관광공사 원문 사진을 복제하지 않고 Commons에서 확인한 CC BY-SA 4.0 / CC0 자료사진을 사용했다. 저자, 촬영일, 라이선스 링크는 `play-tourism-photos.ts` 및 사이트 하단에 표시한다. 리사이즈·화면 크롭은 기존 공개 안내와 같은 방식이다.

- 울산·부산·경북의 고유 여행 계획 설명과 지역 내 장소/축제 연결 페이지 추가.
- 상세 제목·설명·canonical·Open Graph·Twitter 이미지와 텍스트를 장소별로 생성.
- WebPage / TouristAttraction / Place, 검증된 일정의 Event, BreadcrumbList, CollectionPage / ItemList 적용. 미확인 일정은 Event 제외. 주제 참고사진은 Event image 제외. 가격·평점·주최자 등을 추정하지 않음.
- JSON-LD의 `<` 이스케이프로 스크립트 삽입 방지.
- 새 여행지와 지역 페이지, 지난 축제 목록을 사이트맵에 포함. 디자인 샘플의 noindex 유지.
- 실제 순위·검색 유입 개선은 별도 검색 실적이 있어야 판단 가능. 외부 검색 서비스의 신규 색인 요청은 수행하지 않음.

검증: 기존 일정 테스트, SEO 데이터 테스트, 타입 검사, ESLint, 운영용 빌드, 브라우저 메타데이터·이미지·모바일·404·사이트맵 확인.
