# 2026-11-11 축제·데이트 추천 추가

- 공식 관광정보·주최기관에서 일정 확인한 축제·문화행사 10개 추가. 날짜, 주소, 프로그램, 비용 범위와 예약 예외는 각 상세 페이지의 출처로 연결.
- 포항국제불빛축제·게임문화축제·무안 YD는 한국관광공사, 군산·진안·벌교·파주는 지자체, 제주감귤·울산문화·경기미 디저트는 공식 참관 안내를 사용.

- 일반 회원 작성 경로 `/play/share`와 서버 액션의 로그인·계정 상태 확인. 본인 글 수정 가능. 관리자 전용 `/community`와 별도. 검증용 공개 회원 글은 만들지 않음.
- 검증: 날짜/종료/사진/경로/SEO 단위 검사, 조건 저장 회귀, TypeScript·ESLint·운영 빌드, 모바일 화면·사진 로딩·로그인 이동 브라우저 확인.
