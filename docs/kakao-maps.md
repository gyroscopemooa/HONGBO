# 게시글 위치 지도 설정

주소가 있는 게시글은 상세 화면의 홍보 정보 카드 아래에 위치 안내를 표시합니다. 기존 주소도 그대로 사용하며, 상세주소(층·호수)는 `extra.addressDetail`에 저장합니다. DB 스키마 변경은 필요하지 않습니다.

1. [카카오 지도 가이드](https://apis.map.kakao.com/web/guide/)에 따라 카카오 개발자 앱의 지도 사용 설정을 확인합니다.
2. JavaScript 키의 SDK 도메인에 실제 운영 주소(예: `https://www.thehongbo.com`)와 필요한 개발 주소를 등록합니다.
3. 빌드 환경에 `NEXT_PUBLIC_KAKAO_MAP_APP_KEY`를 설정하고 다시 빌드·배포합니다. JavaScript용 공개 키만 사용하고 REST API 키나 Admin 키는 넣지 않습니다.
4. 주소가 있는 상세 페이지에서 건물 위치의 마커, 모바일 지도 크기, 카카오맵 검색 버튼을 확인합니다.

주소 좌표 변환에는 기본 주소만 사용합니다. 새 글은 층·호수를 상세주소에 별도로 입력합니다. 기존 주소는 자동으로 잘라내거나 수정하지 않습니다. 키 미설정, SDK 로드 실패 또는 주소 검색 실패 시 주소와 카카오맵 검색 링크를 제공합니다. 주소가 없으면 위치 안내를 표시하지 않습니다.
