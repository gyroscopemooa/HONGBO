## 범위

- 새 회원 게시판 `/talk`를 추가했습니다. 기존 홍보 카드, `/community` 운영자 가이드 및 `/meetup` 게시글은 보존합니다.
- 대상: 앱, 웹서비스, 게임, 오프라인 가게, 맛집·음식, 화장품, 향수, 의류, 기타 상품, 기타.
- 주제: 테스트, 체험, 피드백, 후기·리뷰, 품앗이, 자유 이야기.
- 기본 제목·본문 중심입니다. 링크, 플랫폼, 지역, 인원, 기간, 혜택·조건, 참여 안내, 내 기존 홍보글 연결은 선택입니다.
- 비공개 참여 신청은 글 작성 시 선택적으로 켭니다. 작성자/관리자는 신청 승인·거절, 신청자는 취소할 수 있습니다. 배송지·연락처 등 별도 개인정보 필드는 수집하지 않습니다.
- 댓글·한 단계 답글, 본인 수정/삭제, 모집 마감/재개, 신고, 관리자 숨김/복원 및 댓글 삭제를 지원합니다.
- 댓글/답글 사이트 내 알림함과 읽음 처리, 헤더 읽지 않은 알림 배지를 추가했습니다.
- 신청 상태는 글의 참여 신청 영역에서 확인합니다. 신청 관련 알림, 이메일 및 모바일 푸시 알림은 이번 구현에 포함하지 않습니다.
- 관리 신고/숨김 목록과 신청 목록은 100개 단위 페이지 이동을 지원합니다. 댓글은 글당 최대 1,000개로 명시적으로 제한합니다.

## 보안·운영

- 서버 인증/계정 제한/작성자 권한을 검증합니다. 신청 정보와 알림은 본인 또는 필요한 관리자에게만 노출합니다.
- Supabase 테이블은 RLS를 적용하고 anon/authenticated 직접 접근을 제한합니다. 서버 전용 서비스 역할이 검증 후 접근합니다.
- 댓글과 알림 생성은 SQL RPC 안에서 원자적으로 처리합니다. 중복 신청 제한, DB 기반 작성 빈도 제한을 포함합니다.
- 솔직한 리뷰, 협찬·보상 공개, 허위 리뷰·평점 강요 금지를 안내합니다.
- DB가 없는 로컬 개발에서만 파일 저장소를 사용합니다. Cloudflare 운영에서 로컬 파일 저장을 데이터베이스 대체 수단으로 사용하면 안 됩니다.

## 검증

최종 `npm run typecheck`, `npm run lint`, `npm run build` 및 신규 회원 게시판·기존 운영자 가이드·중복 방지·Threads 관리 회귀 테스트가 통과했습니다. 로컬 프로덕션 서버 HTTP 검사에서 익명 게시판 렌더, 미인증 글쓰기/알림 로그인 리다이렉트, 비관리자 관리자 페이지 차단, 개발용 회원/관리자 세션의 각 화면 렌더를 확인했습니다. Next.js 스트리밍 응답은 HTTP 200 안에 redirect/404 결과를 포함할 수 있으므로 본문 지시까지 확인했습니다. 새 로컬 저장소 테스트는 분류/검색, 수정, 마감, 숨김/복원, 댓글/답글 경계, 알림 수신자 분리, 삭제 표시, 비공개 신청, 신청 취소/재신청, 비활성 모집, 목록 페이지 및 댓글 한도 등을 검증합니다.

브라우저 E2E 스크립트 `scripts/test-member-browser.cjs`는 준비했으나 현재 환경에서 Chromium이 로컬 socket 권한 오류로 시작하지 못하여 실제 실행 검증을 완료하지 못했습니다. 실제 모바일 시각 검수와 로그인 상태의 서버 액션 E2E는 아직 통과 판정하지 않습니다.

## 출시 전 필수 단계

1. Supabase 테스트 환경에 `supabase/migrations/0013_member_community.sql` 적용 및 SQL/RLS/RPC 검증.
2. 실제 계정 2개와 관리자 계정으로 작성, 댓글/답글 알림, 비공개 신청/승인/취소, 신고/숨김/복원, 차단 계정 테스트.
3. 390px 모바일/데스크톱에서 화면과 반복 클릭, 뒤로가기, 취소, 로그아웃 후 접근 점검.
4. 사용자 배포 승인 범위 확인 후 Git push/운영 배포. 마이그레이션을 먼저 적용해야 `/talk`가 운영 DB에서 동작합니다.

이번 작업은 개발 요청 범위로 로컬 구현이며 운영 DB 적용, Git push, 배포를 실행하지 않았습니다.
