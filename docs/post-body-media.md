# 상세 본문의 사진과 영상

작성·수정 화면의 상세 설명은 한 칸짜리 Tiptap 편집기입니다. 커서 위치에 사진을 붙여넣거나 드래그하고, 유튜브 주소만 붙여넣으면 그 자리에 영상이 들어갑니다. 직접 입력한 유튜브 주소는 Enter 또는 공백으로 영상으로 변환합니다. 일반 링크는 공개 본문에서 클릭할 수 있습니다. 사진·영상은 선택 후 Delete로 지우고 Ctrl+Z로 실행 취소할 수 있습니다. ‘사진 첨부’ 버튼도 커서 위치에 삽입합니다.

기존 텍스트와 블록 형태의 글은 원래 순서와 사진 설명을 유지해 불러옵니다. 새로 편집한 본문은 `extra.bodyFormat=rich`, `extra.bodyBlocks`로 저장하고 `description`에는 검색·검사에 쓰는 전체 본문 텍스트를 둡니다. 공개 페이지는 본문을 중복 표시하지 않습니다. HTML을 저장하거나 실행하지 않으며 DB 마이그레이션은 필요하지 않습니다.

이미지 파일을 복사하거나 화면을 캡처한 뒤 상세 설명에서 Ctrl+V 또는 마우스 붙여넣기를 쓰면 업로드합니다. 일반 텍스트 붙여넣기는 그대로 동작합니다. 다른 웹페이지의 HTML·서식은 제거하고 텍스트만 넣습니다. HTML 안의 원격 이미지를 자동 수집하지 않습니다. 업로드 중에는 커서 위치 보존을 위해 편집을 잠시 멈춥니다.

본문은 최대 16개 블록, 사진 6장, 영상 3개입니다. 상세 설명과 글 블록은 합계 5,000자입니다. 사진은 비율을 유지하며 긴 변 1600px로 줄이고 WebP(지원되지 않으면 JPEG)로 압축합니다. 장당 350KiB를 넘으면 업로드하지 않습니다. 업로드 경로에서도 본문용 파일 크기를 검사합니다. 유튜브는 영상 파일을 저장하지 않고 눌렀을 때 플레이어를 불러옵니다. 본문 사진도 지연 로드합니다.

본문 블록 삭제는 게시글에서 참조를 제거합니다. 기존 이미지 저장소의 파일을 자동 삭제하는 정리 작업은 포함하지 않습니다. 작성 중 업로드 후 저장을 취소한 파일도 저장소에 남을 수 있습니다. 대표·갤러리 이미지의 기존 원본 해상도 보존 정책은 별도입니다.

검증: `npx tsx scripts/test-body-blocks.ts`, `npx tsx scripts/test-body-document.ts`, `node scripts/test-inline-body-browser.mjs`(로컬 Edge 설치 필요), `npm run typecheck`, 변경 파일 ESLint, 프로덕션 빌드. 브라우저 테스트는 별도 임시 프로필과 가짜 업로드 응답으로 실행하며 사용자 로그인이나 운영 데이터는 사용하지 않습니다.
