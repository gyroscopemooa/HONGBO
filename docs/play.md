# 놀러가자

더홍보의 국내 나들이 섹션. 별도 도메인·인증·결제 서비스 없이 `/play`로 운영한다.

- `/play`: 편집 안내 7건(종료 행사 포함), 지역·동행·종류·키워드 필터, 브라우저 내 찜, 최근 회원 소식.
- `/play/[slug]`: 공식 출처·확인일·이용 전 확인 사항·지도 검색·관련 안내.
- `/play/share`: 기존 계정으로 장소·소식을 공개 등록. 기존 서버 액션의 차단 계정·URL 검증·중복·속도 제한·이미지 업로드를 그대로 사용. 외부 SNS 홍보에 자동 동의하지 않는다.
- `/play/shared`: 정확히 `놀러가자` 태그를 가진 공개·미만료·비시드 글을 DB에서 검색/지역 필터/페이지 이동. 기존 내 홍보에서 수정·삭제하며, 태그를 삭제하면 이 섹션에서도 제외된다. 기존 관리자 게시글 관리와 신고 기능 적용.

편집 데이터는 `src/data/play.ts`에서 관리한다. 할인율·가짜 후기·방문 수를 만들지 않으며 공식 사이트에서 상품별 요금과 조건을 확인하도록 안내한다. 소개 이미지는 직접 작성한 SVG 일러스트로 실제 장소 사진이 아님을 표시한다.

편집 축제의 시작일·종료일은 한국 시간 날짜로 비교하며 종료일 당일까지 유효하다. 종료 행사는 기본 탐색에서 숨기고 `지난 행사도 보기`에서 확인한다. 회원 소식의 자유 형식 행사 기간은 자동 판독하지 않는다. 회원 작성 안내에 종료 후 수정·내림을 명시한다.

회원 등록은 기존 posts 테이블과 tags 배열을 사용하므로 DB 마이그레이션이 없다. 새 `ListQuery.tag`는 두 저장소에서 정확한 배열 원소로 비교한다. 전용 관리자 편집 UI, 실시간 최저가 비교, 예약/결제, 해외 여행, 무인 정보 수집은 구현하지 않았다.

검증: `npx tsx scripts/test-play.ts`, `npm run typecheck`, `npm run build`.
