선정 근거
발행 전 운영 DB의 전체 커뮤니티 글은 공개 2편, 초안 0편이었다.
첫 등록 준비와 수정/갱신을 설명한 기존 글과 달리, 내부 검색에서 글이 안 보이는 질문을 해결한다.
검색 실적 CSV와 실제 문의 빈도 자료가 없어 검색 수요·인기도·후기를 주장하지 않는다.
운영 검색에서 ‘채용페이지’ 1건, 일치하지 않는 단어를 덧붙이면 0건이며 추천 영역이 별도로 나오는 것을 확인했다.

주소: https://www.thehongbo.com/search

기존 글 보완 위치 (기존 URL 유지)
1. 첫 등록 준비 글: 실행 순서 마지막에 등록 후 검색 확인 문단 추가. 관련 안내에 새 글 링크 추가. 제한 항목의 계정 작성 제한 안내에 문의 채널 준비 중 상태 반영.
2. 수정/갱신 글: ‘안 되는 경우와 대안’ 마지막에 갱신 후 내부 검색 확인 문단 추가. 관련 안내에 새 글 링크 추가. 권한/상태 문단의 문의 안내를 현재 채널 상태에 맞게 수정.
3. 두 기존 글의 /contact 링크 문구를 ‘현재 제공되는 문의 경로 확인하기’로 통일.

운영 검증
- 신규 글과 기존 두 글 모두 HTTP 200.
- 세 공개 페이지에서 제목, 첫 답변, 실행 순서, 안 되는 경우의 전체 텍스트가 저장값과 일치함을 확인.
- 세 글의 모든 관련 안내 및 서비스 링크 href를 공개 HTML에서 확인.
- DB 전체 글 수 2→3, 신규 제목과 일치하는 글은 정확히 1편.
- /community, /search, /posts?sort=latest, /contact HTTP 200. /mypage는 비로그인 상태에서 로그인 페이지로 이동.
- 일반 문의는 채널 준비 중으로 표시됨. 일반 검색 문제를 신고 기능으로 접수하라고 안내하지 않음.
- 타인의 홍보글 수정·갱신 테스트는 수행하지 않음. 검색 조회와 콘텐츠 게시만 실행.

배포 판단
커뮤니티 상세는 동적 조회하며 DB 변경 후 실제 공개 본문이 바로 반영됐다.
변경 파일은 발행 원고와 기록뿐이며 실행 코드 변경이 없어 별도 Worker 배포를 실행하지 않는다.
기존 src/app/layout.tsx 변경은 이번 작업 범위에서 제외한다.
유료 글쓰기 API·예약 자동화·외부 커뮤니티 게시는 수행하지 않는다.

후속 확인
질문 해결 반응, 관련 안내 클릭, 실제 이용 여부를 확인한다. 커뮤니티 전용 자동 클릭·전환 집계가 있다고 주장하지 않는다.
발행 장애 없음. 일반 문의 채널 준비 중은 기존 서비스 상태이며 이번 콘텐츠 발행을 막지 않는다.
